The Six Gates

A practitioner method for deciding, bounding, and operating AI agents. Six questions, asked in order, each one a gate. One hour, six signed pages.

"We want to build an AI agent." Every architect hears it weekly, and there is no standard method for answering it. The Six Gates is the method I use. Every agent proposal passes through all six, in order, or it does not ship. A gate that leaves no artifact was not passed. It was waved.

GateThe questionYou pass whenSigned by
I JustifyShould this be an agent at all?The sentence is complete with a specific blank, and the checklist part is carved off to a validatorRequester + architect
II GradeHow much can this thing hurt us?The worst day is written, the downstream check is done, the tier is set, and you start at or below itRisk owner
III LimitWho is allowed to write what?Every argument of every reachable tool has a pen, and the human pen is enforced in codeSecurity
IV BuildWhat is the smallest supervised loop?One agent, one checkpoint, a cascade, a log, and an escalation queue with an ownerEngineering lead
V ProveWhat evidence buys its freedom?Frozen set, baseline, thresholds dated before the run, one command to reproduce, harm ruleEval owner
VI RunWho maintains it?A named owner, a ledger in version control, cadences on a calendar, an off switch with a test dateOperations

Three rules. Gates are passed in order. A gate is passed when its artifact is signed, not when the room nods. Failing a gate is a good outcome.

The implementation guide

Running the Six Gates is the 39-page manual for the team in the room: the one-hour run sheet, who signs each gate and what they are signing for, pass criteria, fill-in templates, the promotion path, the ledger layout, a worked example with all six pages filled in, and a glossary. Templates and code, free to use

The six gate templates, a reference tool boundary that enforces who may write each argument, an eval harness that freezes a set and records the hashes, the sixgates command that checks whether every gate was signed or waved, and a worked example are in the repository: github.com/bhargava-dev-ai/six-gates.
